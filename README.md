# Lararium

*/ lārārium / — the household shrine where the protective spirits were kept*

**A personal AI agent that lives at your hearth and rides in your pocket.**
Your machine, your models, your keys.

- [lararium.io](https://lararium.io) — the front door on the web
- [lararium](https://github.com/lararium-app/lararium) — the daemon:
  agent loop, memory, sandbox, and the doors to your screens

## Security

Do not open public issues for vulnerabilities. Write
[security@lararium.io](mailto:security@lararium.io) — acknowledgment
within 72 hours, and credit where credit is due. Details in
[SECURITY.md](https://github.com/lararium-app/lararium/blob/main/SECURITY.md).

## House rules

- **One household, one owner.** The security model is single-trust-domain
  by design; multi-tenant claims will always be out of scope.
- **Files you can read.** Memory, sessions, and config are open formats.
  If a feature needs a proprietary database to work, it is wrong.
- **Proven, not claimed.** Anything the README says works has a test
  suite with its name on it.
- **Honest status.** Shipped is shipped; planned says *planned*. We would
  rather under-promise a landing page than over-promise a release.
